# Championship Studio

App de escritorio para seguir la tabla del campeonato de Formula 1, ver escenarios por piloto o escudería y proyectar cómo puede terminar la temporada.

## Funciones

- Tabla general de pilotos y constructores con puntos, diferencia al líder, techo matemático y rating por rendimiento.
- Análisis de escenarios por puesto (qué resultados necesita cada piloto o equipo y límites frente a sus rivales).
- Gráfico de evolución fecha a fecha para pilotos y escuderías.
- Simulador de probabilidades con ajuste de forma reciente e imprevisibilidad.
- Vista de calendario con tiempos, deltas, vuelta rápida y puntos por fecha.
- Apartado de liga personalizada para armar campeonatos propios con amigos.
- Sincronización de resultados oficiales usando [Jolpica-F1](https://github.com/jolpica/jolpica-f1).

Proyecto personal sin afiliación con Formula 1, la FIA ni escuderías.
